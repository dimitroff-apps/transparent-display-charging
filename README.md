# Transparent Display Charging

Рентгенов изглед на зареждането през дисплея (Xiaomi 15).

## Сглобяване на APK
При всяко качване в клона `main` GitHub Actions сглобява APK автоматично:
- **Releases** → последният `Build N` → `TransparentDisplayCharging.apk` (най-лесно от телефона)
- или **Actions** → последното пускане → **Artifacts**

Всички версии са подписани с един и същ ключ (`app/tdc.keystore`), така че новият APK се инсталира върху стария.

## Какво може
- **Ръчно**: бутон „Покажи анимацията“ (двойно докосване затваря)
- **Автоматично при кабел**: включва се с превключвателя; нужни са „Показване върху други приложения“, „Изскачащи прозорци при работа на заден план“, автостарт и батерия „Без ограничения“
- **Скрийнсейвър при зареждане**: избира се в настройките за скрийнсейвър, ако телефонът ги има
- Теми по модел: разпознава Galaxy S24–S26, Xiaomi 14–17, Pixel 9–11, OnePlus 12–15 и Motorola Edge 50 Ultra / 60 Pro / Signature; за други телефони има 4 универсални теми; темата се сменя от „Избери тема“
- Истински стотни от брояча на заряда (µAh) и реални ватове от тока и напрежението
- **Плъзгане нагоре/надолу** по анимацията: нагоре затъмняването се разтваря като елипса до напълно чиста платка, надолу се затваря до ~95% тъмно; пръстенът и процентите избледняват заедно с черния дисплей; анимацията не спира, а позицията се запомня
